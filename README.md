# Tomas Lydahl - LP

Hej, jag skulle vilja skapa en landningssida för min kund Tomas Lydahl

Jag har bifogat landningssida planeringen för vårt kommande webinar där det står strukturen för landningssidan.

Målgruppen är mellan 30-60 år gamla, därför ska landningssidan inte vara för "ungdomlig" eller avancerad. 

Jag har även bifogat ICP'n för det här webinaret, så att du får en känsla för vem vi riktar oss mot.

Du kan även ta användning av Tomas Lydahl hemsida för att se vilka färgkoder som han brukar använda, här är hans hemsida: https://tomaslydahl.se/ 

Efter att någon har anmält sig så vill jag sedan skapa en tacksida där det är en tacksida video, länk till WhatsApp grupp, dubbekollar mejlen och sedan kan kolla på resterande Tomas YouTube kanaler. Jag har bifogat hela tacksida planeringen som dokument också.
